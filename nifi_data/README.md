# nifi_data

这是本地后端的静默导出兜底目录。

用途：当使用者忘记手动触发定时导出，或者定时任务没有按预期跑起来时，由后端的静默导出链路补做一次导出，保证关键数据仍然能落盘，不至于漏导。

目录约定：
- `exports/`：导出的结果文件。
- `silent_exports/`：静默导出相关的任务记录和中间产物。

说明：
- 这里保存的是本地兜底导出数据，不是面向普通用户手工操作的业务目录。
- 目录内文件主要由后端调度、管理员触发或兜底任务写入。
- 如果后续要清理历史文件，优先确认是否已经被导出任务或审计链路消费完毕，再删除。

维护建议：
- 定期检查静默导出是否正常运行。
- 若发现定时导出缺失，先看这里是否已经生成对应结果。
- 新增子目录时，保持与后端配置和导出链路一致。
