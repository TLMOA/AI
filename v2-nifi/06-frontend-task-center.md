# NiFi 异步任务前端展示方案（内联任务 + 任务中心）

> 适用范围：`v1-frontend`、`v1-backend`、`v2-nifi/` 其他方案文档
>
> 目标：在 NiFi 异步执行时，前端不阻塞、可继续操作；内联任务与任务中心协作但不冗余；仅针对当前用户展示任务。

## 1. 统一原则

1. 单一数据源：内联任务与任务中心共用同一套任务数据来源与状态机。
2. 双视图协作：内联任务负责“当前功能的最近任务队列”，任务中心负责“当前用户的全量任务”。
3. 不分叉逻辑：前端只做筛选，不做额外状态机或独立任务实体。
4. 用户隔离：内联任务与任务中心仅展示当前用户任务，不显示其它用户任务。
5. 异步默认：所有 NiFi 任务提交后返回 `PENDING`，前端不阻塞、允许继续操作。

## 2. 状态机与展示语义

### 2.1 状态机（统一）

- `PENDING`: 已提交到 NiFi
- `RUNNING`: NiFi 正在处理
- `SUCCEEDED`: 处理完成
- `FAILED`: 处理失败

### 2.2 展示文案（建议）

- `PENDING`: 已提交（后台处理中）
- `RUNNING`: 正在处理
- `SUCCEEDED`: 已完成
- `FAILED`: 失败（可查看错误）

## 3. 内联任务（功能页内）

### 3.1 目标

- 用户在当前功能页能即时看到本次提交的状态。
- 连续导出/转换不覆盖状态，显示“最近 N 条任务队列”。

### 3.2 展示规则

- 只显示当前功能类型的最近 N 条任务（建议 N=5）。
- 只展示当前用户任务。
- 展示字段最小集合：
  - `jobId`
  - `status`
  - `createdAt`
  - `finishedAt`
  - `resultFile` 或 `outputs`
  - `errorMessage`（失败时）
- 提供“查看全部任务”入口，跳转任务中心。

### 3.3 连续提交场景

- 连续提交两个导出任务时，内联任务队列显示两条独立记录。
- 后提交的任务不覆盖前一个任务。
- 每条任务有独立的状态变化与结果入口。

## 4. 任务中心（全量任务页）

### 4.1 目标

- 给当前用户一个统一入口查看所有任务。
- 支持筛选与回溯，不干扰功能页流程。

### 4.2 展示规则

- 只显示当前用户任务。
- 展示字段建议：
  - `jobId`
  - `jobType`
  - `status`
  - `progress`（可选）
  - `createdAt` / `startedAt` / `finishedAt`
  - `outputs` / `resultFile`
  - `errorMessage`
- 筛选维度：
  - `jobType`（导出/上传转换/打标）
  - `status`
  - 时间范围（可选）

## 5. 内联与任务中心协作方式

1. 共用数据源：同一个任务列表接口，前端做筛选即可。
2. 内联负责“最近队列”，任务中心负责“全量追踪”。
3. 内联任务提供“查看全部任务”入口，任务中心不反向嵌入内联逻辑。
4. 不重复实现状态机，不做两套任务实体。

## 6. API 约定（对接现有方案）

> 对接方式需与 `V1-NiFi统一实施可执行方案.md` 和后端现有 job 机制保持一致。

建议提供一个统一的“当前用户任务列表”接口：

- `GET /api/v1/jobs`
  - 默认仅返回当前用户任务
  - 支持 query: `jobType`, `status`, `limit`, `offset`

任务详情接口：

- `GET /api/v1/jobs/{jobId}`

备注：如现有实现已包含 `jobs` 与 `jobId`，则只需补齐“当前用户过滤”即可。

## 7. 轮询策略

- 内联任务：提交后立即刷新，随后 3-5 秒轮询，完成后降频或停止。
- 任务中心：进入页面后 5 秒轮询，切出页面后停止。

## 8. 与其他方案的适配关系

- 适配 `V1-NiFi统一实施可执行方案.md` 的异步链路（PENDING -> SUCCEEDED/FAILED）。
- 适配 `02-db-export-flow.md`、`03-upload-convert-flow.md`、`04-auto-tagging-flow.md` 的任务输出结构。
- 与 `V1执行清单/需求规格-NiFi-文件输出.md` 保持一致的响应壳与字段风格。

## 9. 验收标准

- 内联任务不会被连续提交覆盖，能显示最近 N 条任务。
- 任务中心只显示当前用户任务，并支持筛选。
- 内联任务与任务中心共用同一接口与状态机。
- 提交 NiFi 任务后页面不阻塞，可继续操作。
- 任务完成后能在内联或任务中心查看结果文件。

## 10. 对接清单

- 前端：新增内联任务队列（每功能页）+ 任务中心入口与页面。
- 后端：统一任务列表接口，默认过滤当前用户。
- 文档：本文件作为前端展示规范，与 `v2-nifi` 其他方案共同引用。
