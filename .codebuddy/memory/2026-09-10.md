## 修掉的 set -e 陷阱（重要，通用教训）
`deploy.sh` 用 `set -euo pipefail`，以下写法在条件为假时会让脚本直接退出：
- `[[ "$X" == "true" ]] && FLAG="--admin"` → 改为 `if ...; then ...; fi`
- `nginx -t && systemctl enable ... && systemctl reload ...` → 改为 `if nginx -t; then ... else warn; fi`
- `systemctl enable ... >/dev/null 2>&1` 补 `|| warn`
