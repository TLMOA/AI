**踩到的四个真坑（都已修进脚本，值得记牢）**
1. 🔴 **`set -o pipefail` + `grep -q` = 随机变卦**：`apt-cache policy x | grep -qE 'Candidate: [0-9]'` 实测 **rc=141**

## 🖼️ 用户截图抓出登录页乱码 → 根因是注册按钮补丁只包了半截（已修 + 出 v10）

**现象**（目标机登录页截图）：登录按钮下方渲染出一行 `style="background:#28a745;margin-top:8px">注册`。

**根因**：`tools/disable_register_page.py` 旧实现只把 `<button class="btn" id="registerBtn"` 这个**前缀**
替换成 `<!-- ... -->` → 注释在行中间就闭合了，行尾的 `style=...>注册</button>` 全露在注释外，
浏览器把 `style="background:#28a745;margin-top:8px">注册` 当正文渲染。
（e2e 只断言了输出含「已注释」，没断言注释的完整性 → 没拦住。）

**修复**：整行包进注释（保留原始缩进与行尾），且**能自动识别并修复旧版留下的残缺行**（`BROKEN_RE`）
→ 老机器不用卸载重装，重跑一次本脚本即修复。`--revert` 对新旧两种形态都能逐字节还原。

**验证**：6 场景单测（全新→整行注释✓ / 模拟旧版残缺行→修复✓ / 幂等✓ / revert 逐字节还原×2✓ /
register.html 恢复✓）+ e2e 15 步全过。
📝 教训：**给 HTML 打注释型补丁必须断言"注释闭合后行内无残文"**，只断言"打了 MARK"会漏掉这种半截注释。
