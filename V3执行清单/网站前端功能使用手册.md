# AI 模块 V1 前端使用手册

> 适用版本：V3（Local 后端模式），所有修改均不涉及 NiFi。

---

## 顶部全局

| 控件 | 位置 | 用法 |
|------|------|------|
| **Local** / **NiFi** 切换按钮 | 右上角 | 切换后端模式（默认 Local）。影响所有 API 请求的 base URL。文本会提示"当前后端：Local/NiFi" |

---

## 1. 数据库导出卡片

### 1.1 基本连接信息

| 控件 | 用法 |
|------|------|
| **数据库类型** 下拉 | 选 MySQL / PostgreSQL / SQLServer / SQLite / Hive / HDFS / HBase / Oracle。选 HDFS/HBase 时会出现额外字段 |
| **DSN** 输入框 | 可选。填了就优先用 DSN 连接串 |
| **SQLite/HDFS/HBase 文件路径** | 选对应类型后才会显示 |
| **Host** / **Port** | 数据库地址 |
| **Database** / **User** / **Password** | 登录信息 |
| **Table** 下拉 + 输入框 | 先点"列出表"加载，再选；或直接手输表名 |
| **Row Key 前缀** | 仅 HBase 显示 |
| **Where** | 可选过滤条件，如 `id > 100` |

| 按钮 | 用法 |
|------|------|
| **测试连接** | 验证数据库连接是否可用，提示写到 `dbConnStatus` |
| **列出表** | 加载表名到下拉框 |

### 1.2 手动导出

| 控件 | 用法 |
|------|------|
| **格式** 下拉 | 选 CSV / JSON / TSV |
| **追加到 latest** 复选框 | 勾选则把数据追加到同名 latest 文件 |
| **立即导出** 按钮 | 执行导出，结果写到 `dbExportResult`，同时生成 `.meta.json` |

### 1.3 标签配置（手动导出）

| 控件 | 用法 |
|------|------|
| **是否含标签** 下拉 | 必选 |
| → 选"是"：显示"标签列"、"标签名字" | 填列名（如 `tag`）和人类可读名字 |
| → 选"否"：显示"候选标签范围"、"故障标签" | 逗号分隔写范围（如 `故障,预警,正常`），下拉里选故障标签（选项会随范围自动刷新） |

### 1.4 补充信息

| 控件 | 用法 |
|------|------|
| **类别ID** / **类别名称** / **描述** | 可选，写入 `.meta.json` |

### 1.5 定时导出

| 控件 | 用法 |
|------|------|
| **频率** 下拉 | 每5分钟 / 每15分钟 / 每小时 / 每日 / 自定义 cron |
| **自定义 cron** 输入框 | 选 cron 时填写 |
| **创建定时任务** 按钮 | 把上面所有配置保存为定时任务 |
| **管理已有任务** 按钮 | 弹出定时任务管理弹窗，可查看/启停/删除 |

| 弹窗控件 | 用法 |
|------|------|
| **刷新** 按钮 | 重新拉取任务列表 |
| **关闭** 按钮 | 关闭弹窗 |
| 表格中每行的 **启停** / **删除** 按钮 | 控制或删除对应定时任务 |

## 2. 文件中心卡片

### 2.1 文件浏览

| 控件 | 用法 |
|------|------|
| **格式筛选** 下拉 | 按 CSV/JSON/TSV 过滤 |
| **加载文件** 按钮 | 重新拉取当前目录文件列表 |
| **目录树**（左侧） | 点击任意目录切换右侧"当前目录文件"列表 |
| **当前目录文件**（右侧） | 显示 fileId、文件名、格式、大小、操作 |
| → **预览** 链接 | 选中文件后预览 |
| → **删除** 链接 | 删除文件（含 `.meta.json`） |

### 2.2 文件预览 / 标签编辑区

| 控件 | 用法 |
|------|------|
| **offset** / **limit** | 分页参数 |
| **刷新预览** 按钮 | 重新拉取预览内容 |
| **弹窗编辑** 按钮 | 把可编辑表格弹出为模态框 |
| **标签元数据** 蓝色提示条 | 自动展示配套 `.meta.json` 摘要（hasTag、tagColumn、tagName、tagRange、failedTag） |

### 2.3 可编辑表格

| 控件 | 用法 |
|------|------|
| **单元格** | 直接点击编辑（多轮修改可累加） |
| **新增字段** 按钮 | 新增 1 列固定名为 `tag` 的字段（已有 tag 列时禁用） |
| **保存标签** 按钮 | 把当前编辑结果保存到 `tagged_output/` 目录，生成新文件 + `.meta.json` |
| **自动打标** 按钮 | 跳到标签中心并自动填入当前 fileId |

## 3. 标签中心卡片（本地打标模式）

### 3.1 自动标签

| 控件 | 用法 |
|------|------|
| **fileId** | 必填，从文件中心复制或从预览区跳转 |
| **标签名字** | 选填，如"设备状态" |
| **规则名称** | 多列规则的名字 |
| **参与打标的列** | 逗号分隔，如 `device_type,status` |
| **默认标签** | 不匹配任何条件时打的标签，默认"未知" |
| **+ 添加条件** 按钮 | 按"参与打标的列"动态生成输入框，填写 `when` 条件和对应 `tag` |
| **触发自动标签** 按钮 | 用配置好的规则打标，结果落到 `tagged_output/` |
| **刷新规则** 按钮 | 重新拉取规则列表 |
| **`tagResult`** | 显示打标结果信息 |

> **手动编辑入口**：已统一在文件中心可编辑表格里完成，不再单独提供"手动标签"表单。

## 5. 整体典型使用流程

1. **准备数据**：
   - 数据库导出：填连接 → 测试连接 → 选表 → 填标签配置 → 立即导出
   - 文件上传：选转换类型 → 填标签配置 → 选文件 → 上传
2. **查看数据**：文件中心 → 加载文件 → 选目录 → 预览
3. **打标签**：
   - 手动：预览区编辑单元格 → 新增字段（仅可加 `tag` 列）→ 保存标签
   - 自动：标签中心 → 填 fileId → 配多列规则 → 触发自动标签
4. **查看结果**：所有打标后文件都落到 `tagged_output/` 目录
5. **定时任务**：定时导出卡片 → 配频率 → 创建任务 → 管理已有任务
