## 一、注册页改造

### 当前状态 ✅

`register.html` 已添加：
- 部署模式单选按钮（公有化/私有化）
- 私有化模式下显示 Ceph 路径输入框
- 提交时附带 `deployment_mode` + `ceph_endpoint`

### 注册流程

```
用户打开 /register.html
  → 填写用户名、密码
  → 选择部署模式：
    - 公有化（默认）：Ceph 路径隐藏
    - 私有化：显示 Ceph 路径输入框（必填）
  → 点击注册
  → POST /api/v1/auth/register
    {
      "username": "zhangsan",
      "password": "123456",
      "deployment_mode": "public",
      "ceph_endpoint": ""
    }
  → 成功 → 自动跳转登录页
```

### 验证方法

```bash
# 浏览器打开 http://localhost:8000/register.html
# 1. 选择"公有化" → 填写用户名密码 → 注册
# 2. 选择"私有化" → 填写用户名密码 + Ceph 路径 → 注册
# 3. 检查后台目录是否创建
ls /home/yhz/{username}/
ls /home/yhz/{username}/
```

async function deleteUser(username) {
    if (!confirm(`确定删除用户 ${username}？此操作不可恢复。`)) return;
    await fetch(`/api/v1/internal/users/${username}`, {
        method: 'DELETE',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ purge_data: true }),
        credentials: 'include'
    });
    renderUserManagement(); // 刷新列表
}
