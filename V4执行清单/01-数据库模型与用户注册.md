## 一、IotUser 模型扩展

```python
class IotUser(BASE):
    __tablename__ = "iot_users"
    id = Column(Integer, primary_key=True, autoincrement=True)
    username = Column(String(128), unique=True, index=True, nullable=False)
    password_hash = Column(String(256), nullable=False)
    is_admin = Column(Integer, default=0)
    deployment_mode = Column(String(32), default="public")   # "public" / "private"
    ceph_endpoint = Column(String(512), default="")          # 私有化用户的 Ceph 路径
    created_at = Column(DateTime, default=datetime.utcnow)
```

### 字段说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `deployment_mode` | VARCHAR(32) | `"public"` | `"public"` = 公有化，`"private"` = 私有化 |
| `ceph_endpoint` | VARCHAR(512) | `""` | 私有化用户的 Ceph 挂载路径；公有化用户为空 |

## 三、注册 API

**接口**：`POST /api/v1/auth/register`

**请求体**：
```json
{
  "username": "zhangsan",
  "password": "123456",
  "deployment_mode": "public",
  "ceph_endpoint": ""                  // 私有化必填
}
```

**后端注册流程**：
```
register() → 校验参数
  → deployment_mode in ("public", "private")
  → 私有化且无 ceph_endpoint → 400
  → hash 密码
  → INSERT iot_users (username, password_hash, deployment_mode, ceph_endpoint)
  → 调用 _create_user_storage_dirs(username, deployment_mode, ceph_endpoint)
  → 返回成功
```

## 四、注册时自动创建目录

`_create_user_storage_dirs` 函数（在 `auth.py` 中）：

```python
def _create_user_storage_dirs(username: str, deployment_mode: str, ceph_endpoint: str):
    """为用户创建 nifi-data 和 real_nifi_data 目录"""
    if deployment_mode == "private" and ceph_endpoint:
        root = Path(ceph_endpoint)
    else:
        root = IN_DATA_BASE_DIR / username  # /home/yhz/{username}
    (root / "nifi-data").mkdir(parents=True, exist_ok=True)
    (root / "real_nifi_data").mkdir(parents=True, exist_ok=True)
```

### 注册后目录效果

| 场景 | 创建的目录 |
|------|-----------|
| 公有化 `zhangsan` | `/home/yhz/zhangsan/nifi-data/`、`/home/yhz/zhangsan/real_nifi_data/` |
| 私有化 `wangwu` (ceph=/home/yhz/wangwu) | `/home/yhz/wangwu/nifi-data/`、`/home/yhz/wangwu/real_nifi_data/` |

## 五、验证方法

```bash
# 注册公有化用户
curl -X POST http://localhost:8000/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"zhangsan","password":"123456","deployment_mode":"public"}'

# 注册私有化用户
curl -X POST http://localhost:8000/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"wangwu","password":"123456","deployment_mode":"private","ceph_endpoint":"/home/yhz/wangwu"}'

# 验证目录已创建
ls /home/yhz/zhangsan/
ls /home/yhz/wangwu/
```

## 六、管理员删除用户

**接口**：`DELETE /api/v1/internal/users/{username}`

```bash
curl -X DELETE http://localhost:8000/api/v1/internal/users/zhangsan \
  -H "Cookie: access_token=<admin_token>" \
  -H "Content-Type: application/json" \
  -d '{"purge_data": true}'
```

- 删除 `iot_users` 记录
- 删除关联的 `export_jobs` 记录
- 删除 `/home/yhz/{username}/` 目录（`purge_data=true` 时）
